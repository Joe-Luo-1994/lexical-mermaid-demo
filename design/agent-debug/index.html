先確認 listener 更新的業務語意，才能製作保持相同行為的候選 patch。不能直接刪除必要功能來換速度。

介入與控制

只調整這個 listener 發起的更新；固定文件、viewport、字型、快取/reset、必要內容與操作。

如何判讀

  • 更新減少且阻塞下降：支持繼續驗證此路徑。
  • 更新減少但阻塞不變：削弱此解釋，轉查 layout。
  • 內容或行為變了：比較無效，不能算改善。
