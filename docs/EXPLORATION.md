## 第一輪產品狀態

可操作：單鍵錄製、事件摘要、證據選取、相同 build 的設定介入比較、JSON 匯入匯出、手動 OpenCode 交接、零依賴 CLI、選用的 V2 plugin。

尚待使用者驗證：是否更快找到有效實驗、哪些文字或介面造成理解摩擦、公司專案的接入成本、OpenCode Web 實際對話。

## 下一輪最小實驗

1. 使用者在本機依 README 跑正常與重複案例，未經口頭指導完成查看證據及比較。
2. 先用 CLI 讀一份 recording，再選擇是否啟用 V2 plugin；確認同一 report/event ID 在對話與頁面對得起來。
3. 公司環境先錄取一次慢匯入的 Chrome trace，確認缺的是 source/plugin 身分還是其他證據，再決定額外 instrumentation。
4. 保持圖表來源／版本／設定固定，改變周圍文件規模。若成本隨文件增加，觀察 browser trace 的 layout／JS 分布後才選隔離或去重方案。

開始前保留原始判準；若新證據推翻假設，更新這張表，不修改舊結果。
